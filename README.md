# CalculaFácil 🧮

A practical Android utility app that brings multiple everyday calculation tools together in one simple and easy-to-use application.

Built entirely with **Kotlin** and **Jetpack Compose**, CalculaFácil was designed with a focus on usability, reliability, offline functionality, and automated testing.

## 📱 About the Project

CalculaFácil is an Android application that provides a collection of practical calculation tools for everyday situations.

The project was developed as part of my Android development portfolio, with an emphasis on:

* Clean and maintainable code
* Modern Android development
* Reusable UI components
* Automated testing
* Offline-first functionality where applicable
* Responsive user interface
* Practical real-world features

## ✨ Features

CalculaFácil currently includes **23 calculation tools**, covering different everyday scenarios.

Some of the available functionality includes:

* Everyday calculations
* Financial calculations
* Percentage calculations
* Practical utility calculators
* Employment-related calculations
* Other specialized calculation tools

The application is continuously evolving, with improvements and additional tools planned for future releases.

## 🚀 Getting Started

### Requirements

* Android Studio
* Android SDK
* JDK
* Android device or emulator

### Clone the repository

```bash
git clone https://github.com/cristianevertondev/CalculaFacil.git
```

### Open the project

Open the cloned project in **Android Studio** and allow Gradle to synchronize the project.

### Build

You can build the project using Android Studio or Gradle:

```bash
./gradlew build
```

### Run tests

Run the unit tests with:

```bash
./gradlew test
```

For Android instrumentation tests, use an available Android emulator or physical device.
